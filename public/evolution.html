✔ Modo Local Direto Ativado:
Esse modo conecta seu WhatsApp diretamente pelo Node.js, sem precisar de Docker, Linux ou Evolution API instalada externamente. Todas as mensagens enviadas no seu grupo (ex: Uber) são interpretadas e registradas automaticamente nas corridas!
⚙️ Configurações da Evolution API Externa
Use este modo se você já possui uma Evolution API rodando em uma VPS, servidor na nuvem ou container Docker ativo.
💡 Passo a passo para conectar:
  1. Clique em ⚡ Gerar / Atualizar QR Code acima.
  2. Abra o WhatsApp no celular → Menu (3 pontinhos) ou Configurações → Aparelhos conectados → Conectar aparelho.
  3. Aponte a câmera para o QR Code na tela.
  4. Assim que conectar, qualquer lançamento enviado no grupo (ex: 25 joao 14:30 ou odo 45000) cai direto no seu relatório!
